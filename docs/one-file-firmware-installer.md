# One-file S3/C5 firmware preparation

Optional workflow for users with an existing generated `C5FirmwareImage.h` and a current checkout of this repository. It assembles the complete S3 project from checked-in current sources and the supplied C5 image, without modifying the original firmware source. **It does not synthesize new firmware source code** or automatically download GitHub changes; run `git pull` beforehand if you need the latest S3 implementation. The C5 header must be generated by the official package script or extracted from a successful Actions artifact, not the deliberately empty source placeholder.

From repository root on Mac:

```bash
python3 tools/prepare_s3_from_c5_header.py ~/Downloads/C5FirmwareImage.h
```

This creates `prepared-firmware/CuteDisplayBrain/` containing the existing latest `.ino` and support `.h` files plus your replacement C5 header. Open `prepared-firmware/CuteDisplayBrain/CuteDisplayBrain.ino` in Arduino IDE, select ESP32S3 Dev Module, 16M flash, OPI PSRAM and Custom partition scheme, then upload to S3.

To compile automatically (Arduino CLI and ESP32 core 3.3.12 required):

```bash
python3 tools/prepare_s3_from_c5_header.py ~/Downloads/C5FirmwareImage.h --compile
```

Optional explicit S3 upload (physical-device write): add `--upload --port /dev/cu.usbmodemXXXX`. The S3 then installs any newer C5 firmware over UART. No iPhone app update unless Swift changed.

**For most users the GitHub Actions `CuteDisplay-S3-with-C5-update` artifact is simpler** because it *already contains* the fully generated combined S3 project. Don't swap its generated header with the empty source header.
